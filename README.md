# Bluejay Thor 0.7.2-thor.1

[Download the ARM64 APK](BluejayThor-0.7.2-thor.1-arm64-v8a-debug.apk?download=1)

Unofficial development preview for the AYN Thor. Package `com.tufein.bluejay.thor`,
version code 7002; Android 9 or newer. Signed with the same preview certificate as
0.7.1-thor.1, allowing an in-place update.

This update fixes unknown-duration seeking, controller remapping and overlapping
speed holds, per-device disconnect cleanup, stale/duplicate comment pagination,
and unnecessary live-chat start requests.

91 JVM tests and 16 Android instrumentation tests passed without failures or skips.
Physical Thor and online source/casting playback still need hardware/service checks.
